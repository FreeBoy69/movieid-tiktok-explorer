# Landing Page Component Spec

## `LandingPage`

- Owns the public marketing route only.
- Derives its sign-in link from existing auth configuration.
- Displays an OAuth configuration note only when Google OAuth is unavailable.

## Product Illustrations

- Use accessible semantic labels and clearly marked illustrative data.
- Represent existing AutoYT concepts: Radar, candidate scoring, editing tools, source rotation, and release planning.
- Do not resemble third-party product screenshots.
